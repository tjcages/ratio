## Ratio 0.4.1

- **Signed and notarized.** Ratio is now signed with a Developer ID and notarized by Apple, so macOS opens it without the "Open Anyway" step.
- If you're updating from 0.4.0, macOS asks once more for browser Automation access, because the app's signature changed.

### Install

Download **Ratio.dmg**, open it, and drag Ratio into Applications.

Universal app for Apple silicon and Intel, macOS 12 or newer. Open at login needs macOS 13 or newer.
